# Study Claim Bot v16

Telegram-бот для учебной группы: ученики занимают пункты через общее меню в группе, а администраторы настраивают всё в личной переписке с ботом.

## Для учеников

В учебной группе:

```text
/menu
```

Бот показывает предметы → параграфы → пункты и кто что занял.

Лимиты по предметам продолжают работать: если по истории установлен максимум 4, один человек не сможет занять пятый пункт по истории.

## Новая админка

Администратор пишет боту **в личные сообщения**:

```text
/admin
```

Бот показывает группы, где этот пользователь является администратором. После выбора группы все изменения применяются именно к ней.

Через личную админку можно:

- добавлять предметы;
- удалять предметы с подтверждением;
- ставить лимит пунктов на человека;
- добавлять параграфы;
- добавлять пункты `+1`, `+3`, `+5`, `+10`;
- удалять последние пункты `-1`, `-3`, `-5`, `-10`;
- видеть количество занятых и свободных пунктов.

Занятые последние пункты удалить нельзя — сначала их нужно освободить.

## Как бот узнаёт о группе

Telegram Bot API не даёт боту команды «показать все группы, где ты состоишь». Поэтому бот хранит список известных учебных групп в своей базе.

Если нужная группа не появилась в личной `/admin`, один раз отправьте в этой группе:

```text
/menu
```

После этого снова напишите боту в личке `/admin`.

Старые группы, в которых уже были предметы в базе, также автоматически добавляются в список при запуске v6.

## Обновление с v5

Можно сохранить прежний файл:

```text
study_bot.sqlite3
```

При запуске v6 таблица известных групп создастся автоматически. Предметы, параграфы, пункты, занятые места и лимиты сохраняются.

## Установка

Python 3.10+

```bash
pip install -r requirements.txt
```

Создайте `.env`:

```env
BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
DB_PATH=study_bot.sqlite3
```

Запуск:

```bash
python main.py
```


## Полное удаление параграфа

В личной админке:

`/admin` → группа → предмет → параграф → `🗑 Удалить параграф`

Перед удалением бот показывает подтверждение и сообщает:

- сколько всего пунктов в параграфе;
- сколько из них сейчас занято.

После подтверждения удаляется сам параграф, все его пункты и все текущие занятия этих пунктов. Остальные параграфы предмета не изменяются.


## Резервная копия базы

В личке с ботом владелец может написать:

```text
/backup
```

Бот создаст консистентную резервную копию SQLite и отправит файл `.sqlite3` прямо в Telegram.

Чтобы никто другой не мог скачать общую базу, команда защищена `BOT_OWNER_ID`.

1. В личке с ботом введи `/id`.
2. Скопируй свой Telegram ID.
3. Добавь в `.env`:

```env
BOT_OWNER_ID=123456789
```

4. Перезапусти бота.

После этого `/backup` будет работать только у указанного владельца.


## Главный админ и админы бота

Главный админ задаётся в `.env`:

```env
BOT_OWNER_ID=123456789
```

Только главный админ может:

- добавлять и удалять админов бота;
- скачивать `/backup`.

В личке:

`/admin` → `👤 Админы бота` → `➕ Добавить админа`

Нужно ввести Telegram ID человека. Он может узнать свой ID через `/id`.

Добавленные админы бота могут менять обычные настройки групп: предметы, лимиты, параграфы, пункты. Они не могут менять список админов бота и не могут скачивать общую БД.

Обычные Telegram-администраторы группы также сохраняют доступ к настройкам своей группы.

## Диапазон параграфов

При создании предмета можно указать диапазон:

```text
3-7
```

Будут созданы §3, §4, §5, §6, §7.

Одинарное число сохраняет старое поведение:

```text
5
```

создаст §1–§5.

Команда `/setup` тоже поддерживает диапазон:

```text
/setup История | 3-7 | 5
```

## Нумерация после удаления

У каждого предмета хранится отдельный счётчик следующего параграфа.

Например, были §3–§7. Если удалить §3, новый параграф будет §8, а не §3 и не §1.

Если затем удалить §8, следующий всё равно будет §9.


## Автоудаление меню из группы

Для каждой группы можно отдельно настроить, через сколько удалять сообщение бота после `/menu`.

В личке:

`/admin` → группа → `🧹 Меню`

Доступны варианты:

- 30 секунд;
- 1 минута;
- 5 минут;
- 10 минут;
- 30 минут;
- 1 час;
- не удалять.

По умолчанию для старых и новых групп установлено **5 минут**.

Бот хранит очередь удаления в SQLite. Поэтому если бот перезапустился, просроченные меню будут удалены после следующего запуска.

Удаляется именно сообщение бота с меню. Команда пользователя `/menu` остаётся как обычное сообщение Telegram.


## Настройка сообщения /menu

В личной админке:

`/admin` → группа → `📝 Текст /menu`

Можно изменить подпись `Выбери предмет, затем параграф и нужный пункт.`, убрать её полностью или вернуть стандартный вариант. Заголовок `📚 Предметы` остаётся.

Внутри каждого предмета есть `✏️ Переименовать предмет`.

## Произвольное время автоудаления

`/admin` → группа → `🧹 Меню` → `⏱ Своё время`

Поддерживаются, например:

- `19` — 19 секунд;
- `45с` — 45 секунд;
- `2мин` — 2 минуты;
- `1ч` — 1 час;
- `0` — не удалять.

Максимум — 7 дней. Очистка проверяется примерно раз в секунду, а очередь хранится в SQLite и переживает перезапуск.

## Автоматический доступ Telegram-администраторов

Бот запоминает группу сразу при добавлении в неё. Обычный администратор Telegram-группы автоматически получает доступ через личную `/admin` только к тем группам, где он действительно администратор. Дополнительно выдавать ему роль «админ бота» не требуется.


## Свой заголовок `/menu`

В личной админке:

`/admin` → группа → `🏷 Заголовок /menu`

Стандартное:

`📚 Предметы`

можно заменить на любой текст, например:

`✨ Наши предметы`

Поддерживаются Telegram custom emoji / анимированные эмодзи. Бот сохраняет `custom_emoji_id` и показывает такой эмодзи в заголовке сообщения `/menu`.

Также доступны:

- `/default` — вернуть `📚 Предметы`;
- `/empty` — полностью убрать заголовок.

Текст под заголовком по-прежнему настраивается отдельно через `📝 Текст /menu`.

## Автоудаление команды пользователя `/menu`

Когда пользователь отправляет `/menu` в группе, бот пытается сразу удалить именно это сообщение пользователя.

Для этого у бота в группе должно быть администраторское право **«Удалять сообщения»**.

Если права нет, команда останется в чате, но меню всё равно будет отправлено и продолжит работать.

Это отдельно от автоудаления сообщения самого бота: время жизни меню всё ещё настраивается через `🧹 Меню`.


## Своя команда вместо `/menu`

Главный админ может открыть:

`/admin` → группа → `⌨️ Команда меню`

и поставить, например:

`/предметы`

После этого пользователи этой группы вызывают меню через `/предметы`.

Вернуть стандартную команду можно через `/default`.

Кириллица поддерживается обработчиком самого бота, поэтому команда может работать даже если Telegram не показывает её в стандартном списке slash-команд.

## Ограничение прав админов

Настройки оформления и поведения меню доступны **только главному админу (`BOT_OWNER_ID`)**:

- команда меню;
- заголовок меню;
- текст меню;
- время автоудаления меню.

Дополнительные админы бота и обычные Telegram-администраторы группы могут управлять обычной учебной структурой своей доступной группы:

- предметами;
- лимитами;
- параграфами;
- пунктами;
- занятиями.

Они не видят кнопки настройки команды/заголовка/текста меню в своей админке.


## Исправление `/admin`

В v15 настраиваемая slash-команда меню стояла в роутере раньше `/admin`,
из-за чего могла перехватывать `/admin` и другие команды.

В v16 порядок исправлен:

1. `/admin`, `/backup`, `/id`, `/help` и остальные системные команды;
2. FSM-состояния админки;
3. только после них — пользовательская команда меню, например `/предметы`.

Поэтому `/admin` в личке снова работает независимо от того, какая команда меню настроена в группе.

## Группа появляется автоматически

Чтобы группа появилась в личной `/admin`, достаточно:

1. добавить бота в группу;
2. если нужно удаление `/menu` пользователя — выдать ему право **Удалять сообщения**.

Бот слушает update `my_chat_member` и сохраняет группу в `known_groups`
сразу при добавлении или при выдаче прав администратора.

Писать `/menu` для первоначальной регистрации группы не требуется.

Обычный администратор Telegram-группы после этого может открыть бота в личке,
написать `/admin` и управлять разрешёнными настройками своей группы.
